# ANALISI
L'analisi di un dato/dispositivo deve rispondere a delle domande che sono:
- **chi?**
- **Cosa?**
- **Dove?**
- **Quando?**
- **Perché?**
L'analisi deve ricostruire eventi passati mediante la lettura di dati digitali.
Per fare questo tipo di analisi sono strumenti **software** e **hardware**.

# SMARTPHONE
## CRITTOGRAFIA (SMARTPHONE)
Si basa sul principio di cifratura simmetrica, cioè la stessa chiave cifra e decifra i dati e, senza in pratica sono irrecuperabili.

### CIFRATURA DEL VOLUME
- Un'unica chiave protegge l'intera memoria di massa
- Denominata **Full Disk Encryption (FDE)**

### CIFRATURA PER FILE
- Ogni file, gruppo di file è protetto da una chiave distinta
- Chiamata **File Based Encryption (FBE)**
