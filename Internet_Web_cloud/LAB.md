# DJANGO
**DJANGO**: framework di python che permette di scrivere web app, si basa un un modello **Model Template View**(MTV).

Django è dotato di **ORM** cioè le interrogazioni a DB verranno fatte tramite **linguaggio python**, per questo non servono query, infatti django tradurrà il codice py, in query in base al DB, che sia MSQL, SQLSERVER ecc...

## MTV
- **MODEL**:
	==Definisce la struttura dei dati==, cioè rappresenta con delle classi py il DB
- **TEMPLATE**:
	==Definisce la rapprsentazione grafica==, come l'utente interagisce con il programma
- **VIEW**:
	==Definisce la logica==, cioè analizza le richieste web e ne gestisce l'interazione con il db.
